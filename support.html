Helm Support

Helm shows your Mac's screen, a terminal and its files on your iPad.

Set up your Mac

  1. On the Mac, open System Settings → General → Sharing.
  2. Turn on Screen Sharing. This is all Helm needs to show the screen.
  3. Turn on Remote Login as well if you want the terminal and files.
  4. In Helm, tap Nearby and pick your Mac, or tap + and type its address.
  5. Sign in with your Mac user name and password.

Faster screen with Helm Host

Helm Host is a small, free helper for the Mac. It sends the screen to Helm as video, which is smoother and sharper than Screen Sharing.

  1. Connect to the Mac in Helm. If Remote Login is on, Helm offers to install Helm Host; you can also tap ••• → Install Helm Host on This Mac.
  2. On the Mac, in the Helm Host window, click Allow for Screen Recording and for Accessibility, and turn each on in System Settings. You can do this from the iPad through Helm.
  3. Helm switches to Helm Host by itself.

You can also download Helm Host yourself: github.com/xLuciferSx/helm-app/releases

Common questions

My Mac doesn't appear under Nearby.

Make sure the iPad and the Mac are on the same network, and that Helm is allowed in iPad Settings → Privacy & Security → Local Network. You can always add the Mac by its address, shown in System Settings → General → Sharing.

The password isn't accepted.

Use your Mac account's user name and password. If the Mac asks for a separate VNC password (Screen Sharing → ⓘ → "VNC viewers may control screen with password"), turn on "Use a VNC password instead" in the connection's settings.

The terminal or files don't connect.

Remote Login must be on, and your user must be allowed to use it (System Settings → General → Sharing → Remote Login → ⓘ).

Can I connect away from home?

Yes, if your Mac can be reached from where you are, for example through a VPN. Helm itself has no relay service.

Does Helm work with Windows or Linux?

With any computer that runs a VNC server. The terminal works with any SSH server.
